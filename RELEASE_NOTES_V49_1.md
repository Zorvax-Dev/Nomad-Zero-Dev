# V49.1 — Polish monde & lisibilité

## Monde et zones
- Ajout d’un voile d’ambiance très léger selon la zone traversée.
- Ajout d’un bandeau d’entrée de zone avec titre et contexte.
- Ajout d’un conseil ou avertissement temporaire propre à la zone.
- Les événements du Rift restent prioritaires sur les informations contextuelles.

## Combats
- Nouveau placement des apparitions ennemies avec score d’espacement.
- Les ennemis lourds, mini-boss et boss demandent davantage d’espace que les unités légères.
- Objectif : réduire les paquets visuellement brouillons sans diminuer la pression des vagues.

## Version
- Sources Godot : 49.1.0.
- Cette modification concerne le dépôt de développement uniquement.
- Le build Web/PWA est désormais validé, exporté et remis à jour automatiquement par GitHub Actions après les changements de source sur `main`.
